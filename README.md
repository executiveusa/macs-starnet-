# MACS Command City

Private command center for MACS Digital Media. MAXX is the front door and dispatcher. The first checked-in slice includes a local runtime, a nontechnical district overview, empty client/content registries, daily reports, connector contracts, and hard policy gates.

See [setup](docs/SETUP.md), [architecture](docs/ARCHITECTURE.md), and the [build contract](ops/icm/BUILD-CONTRACT.md).

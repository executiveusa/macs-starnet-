# PRD: UI/UX Pro Max skill
**Job:** give builders design references while the landing director governs evidence, clarity, and independent review.
**To production:** pin upstream/version/license; document local delta; test CLI in sandbox; constrain outputs to suggestions; integrate with page-spec and accessibility checks; never let style recipes override brand, copy approval, evidence, or product truth.
**Acceptance:** generated recommendation cites its inputs and passes the independent landing gauntlet on a fixture.
**Stops:** no direct production writes or self-approval.

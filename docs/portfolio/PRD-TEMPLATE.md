# Production PRD template

- **Job:** the one user outcome this product owns.
- **Boundary:** what this repo owns and what stays elsewhere.
- **Production gates:** functional, security/privacy, operations, product proof, landing-page gauntlet, and Max-server portability.
- **Acceptance:** source-bound tests and one live end-to-end journey.
- **Stop conditions:** claims or actions that may not ship without proof/approval.

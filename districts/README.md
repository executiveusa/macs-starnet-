# MACS districts

Each district is a bounded capability lane. The visible status must match its connector and policy state. Empty means empty, not simulated. No district may bypass `config/policies.json`.

- **Dispatch:** MAXX receives work and can hand bounded tasks to configured agents. The Instinct relay uses separate outbound and callback credentials, correlation IDs, idempotency keys, and receipts.
- **Clients:** confirmed client records only. No sample businesses are shown as real.
- **Social:** PostaStudios/TryPost integration for calendars and drafts. Publishing requires approval.
- **Publishing:** blog and content registry. Draft by default.
- **Websites:** Bluehost read and managed change lane. Writes require approval.
- **Voice:** hands-free conversation, interruption, and action readback. Provider setup is separate.
- **Crypto Watch:** education, current information, source tracking, and user-supplied portfolio tracking. Trades, transfers, signing, bets, and wagers are blocked.
